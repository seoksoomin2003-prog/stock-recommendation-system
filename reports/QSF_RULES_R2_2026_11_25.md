# 규칙 R-2: 점수 옆의 말을 기록이 받쳐 주는 만큼으로 (2026-11-25)

사용자 결정(2026-11-25). 근거는 지금 공식의 과거 재현(BT-1, `reports/qsf/QSF_BACKTEST_CURRENT_*.json`, 정오표 `QSF_BACKTEST_CURRENT_ERRATA.md`)과 다섯 자리 토론(`reports/reliability_debate_2026_11_25/`)입니다. 다섯 자리 모두 찬성했습니다.

**점수는 바뀌지 않습니다.** 공식은 QSF-1.6.0으로 동결된 그대로이고, 70점과 80점 선, 완충 구간(67점), 진입 규칙, 주문 계획, 모의 장부, 원장에 적히는 구간 코드(`BUY_CANDIDATE` 등)도 그대로입니다. 바뀌는 것은 화면과 알림의 이름입니다. R-1로 기록된 거래일은 없습니다(R-1은 2026-11-25에 만들어졌고, 첫 기록은 2026-11-26 아침에 R-2로 적힙니다).

## 1. 바뀐 이름

| 코드 | 이전 | R-2 |
|---|---|---|
| `STRONG_BUY_CANDIDATE` (80점 이상) | 강력 매수 후보 | 최상위 구간 |
| `BUY_CANDIDATE` (70점 이상) | 매수 후보 | 상위 구간 |
| `HOLD_WATCH` (55점 이상) | 보유·관찰 | 보유·관찰 (그대로) |
| `WEAK_REDUCE` (40점 이상) | 약세·축소 후보 | 하위 구간 |
| `SELL_AVOID` (40점 미만) | 매도·회피 후보 | 최하위 구간 |
| 판단 `BUY` | 매수 후보 | 상위 구간 |
| 판단 `REDUCE` (보유, 55점 미만) | 비중 축소 검토 | 하위 구간(보유 중) |
| 판단 `SELL` (보유, 40점 미만) | 매도 검토 | 최하위 구간(보유 중) |
| 판단 `AVOID` (미보유, 55점 미만) | 신규 진입 회피 | 하위 구간 |

| 장기 진입 사유 | 분할 진입 기준 구간입니다 | 막는 조건이 없다는 뜻이고 좋은 때라는 뜻은 아닙니다 |
| '사도 돼?'의 결론 `OK` | 사도 됨 | 막는 것 없음 |

'기다림'과 '사지 않음'은 그대로입니다. 보유 종목의 '청산 검토', '비중 축소 검토', '투자 논리 무효'는 점수가 아니라 청산 조건(손절, ROE 하락, 희석, 중대 공시, 모멘텀·시장 급악화)에서 나오는 말이라 그대로입니다.

## 2. 왜

- 70점 이상 묶음이 지수보다 높았던 칸이 네 점수 열두 칸 가운데 하나도 없었습니다(열한 칸 음수, 한 칸 0).
- 이전 공식의 미국 스윙 80점 이상은 다섯 구간 가운데 가장 나빴습니다(`QSF_CORRECTED_OPEN.json`).
- 지금 스캔 대상에서는 맨 아래 묶음이 주된 기간에 지지 않았습니다(한국 장기 252거래일은 맨 아래가 가장 높았습니다). 낮은 점수만으로 "판다", "피한다"고 말할 기록이 없습니다. 피할 근거가 나온 쪽은 점수가 아니라 따로 붙는 회피 표시입니다.
- 이 결과는 같은 구간을 여러 번 읽은 것이라 새 증거가 아닙니다. 이름을 낮추는 쪽은 근거가 없어도 정직한 방향이어서, 과거 재현만으로 정했습니다.

## 3. '매수 후보'가 돌아오는 조건

한 점수(시장 × 전략)의 이름은 **그 점수의 실전 판정**(`QSF_LIVE_FORWARD_PROTOCOL.md`) 또는 스윙의 이어 읽기(`QSF_AFTER_VERDICT_RULES_2026_11_25.md`)가 `WEAK_POSITIVE_EVIDENCE`(순위와 돈 모두)로 읽혔을 때만 돌아옵니다. `RANK_ONLY`로는 돌아오지 않습니다. 순위만 맞는 점수에 맞는 말은 지금의 '상위 구간'입니다.

- 프로그램이 판정 결과 파일을 읽어 스스로 적용합니다(`terminal/qsf/wording.py`). 사람이 할 일은 없습니다.
- **이것은 "잠시"가 아닙니다.** 진짜 순위 상관이 0.05여도 두 조건을 모두 채울 확률은 6.7~8.7%입니다(통계 자리의 모의실험). 중립 이름은 여러 해 갈 가능성이 높습니다.
- 스윙 첫 판정은 2027년 12월쯤, 장기는 2030년쯤입니다.

### 3.1 무엇을 통과로 치는가 (2026-11-25 같은 날 보강, 사용자 결정)

같은 날 점수 감사의 반대편 담당이 이 길의 구멍을 찾았습니다(`reports/score_reliability_audit_2026_11_25/AGENT_08_INDEPENDENT_RED_TEAM.md`): 판정 파일의 낱말 한 칸만 읽어서, 손으로 쓴 파일이나 다른 시장·다른 공식의 파일로도 이름이 돌아왔습니다. 표본의 첫 수익이 만기되기 전에, 그리고 R-2로 적힌 거래일이 생기기 전에 아래로 고쳤습니다. **판정 자체의 조건과 낱말은 바꾸지 않았습니다.** 아래는 이름이 돌아오는 데만 쓰입니다.

| 확인 | 내용 |
|---|---|
| 프로그램이 쓴 파일인가 | 판정을 쓸 때 파일의 해시를 `data/qsf/verdict_seals.json`에 적고, 읽을 때 맞춥니다. 손으로 쓰거나 고친 파일은 치지 않습니다 |
| 맞는 판정인가 | 상태가 `REAL`, 시장과 전략이 같음, 등록된 기간(스윙 20, 장기 63거래일), 등록된 거래일 수(240 / 756, 이어 읽기는 480 / 720 / 960), 표본 시작이 2026-11-25 이후 |
| 낱말이 수치로 받쳐지는가 | 순위 조건 다섯이 모두 참, 돈 조건이 참, t가 그 판정의 기준 이상 |
| 수익 쪽 세 가지 | 배당을 뺀 가격만으로도 지수를 이김, 점수 효과가 전·후반 모두 양수, 상위·하위의 중앙값 차이가 양수. 판정 보고에 이미 적히는 값입니다 |
| 같은 공식인가 | 표본의 공식 버전이 하나이고 지금의 공식 버전과 같음 |
| 이어 읽기 | 첫 판정과 앞선 이어 읽기 파일이 모두 있을 때만 |

수익 쪽 세 가지를 더한 까닭: 돈 조건은 기준 없이 부호만 봅니다. 점수 효과가 전혀 없어도 14~41% 확률로 채워지고(대상이 지수를 이긴 해), 한국은 배당만으로도 채워질 수 있습니다. 돈에 t 기준을 붙이지 않은 까닭은 연 3%p의 우위를 가려내는 데 13년에서 70년 넘게 걸리기 때문입니다.

### 3.2 이름이 내려가는 길

- **공식 버전이 바뀌면** 이름이 스스로 내려갑니다. 옛 공식의 판정이 새 공식의 이름을 받치지 않습니다.
- 판정 파일이 없어지거나 손상되거나 해시 목록(`verdict_seals.json`)이 없어져도 내려갑니다. 모자라면 이름을 주지 않는 쪽입니다. 백업에서 두 파일을 함께 되돌리면 돌아옵니다.
- 통과 뒤에 기록을 다시 읽어 내리는 읽기는 두지 않았습니다(사용자 결정).

## 4. 이 변경이 하지 않는 것

- 주문은 바뀌지 않습니다. 실제 스윙 주문은 구간이 아니라 진입 상태에서 나오고, 2026-11-24 기록에서 진입 상태가 채워진 카드는 모두 55~70점이었습니다. 실계좌 스윙 주문과 장기 종목을 채우는 방식은 사용자 결정(2026-11-25)으로 그대로입니다.
- 색과 정렬은 그대로입니다. 이름만 바꾸고 색이 그대로면 효과가 작을 수 있다는 지적이 토론에 있었습니다.
- 투자위원회(IC-1)의 다섯 관점이 쓰는 말은 점수의 구간 이름이 아니어서 그대로입니다.

## 5. 검증 안내문

`config.VALIDATION_NOTICE`를 점수마다 한 줄로 다시 썼습니다. 지수 대비 숫자는 넣지 않았습니다. 한국의 지수 대비 숫자에는 점수와 무관한 차이가 섞여 있고(정오표 2번), 화면에 늘 떠 있는 숫자는 예측처럼 읽히기 때문입니다.
