# 새 점수 연구 계획 (사전 고정)

작성일: 2026-11-05. 요인별 결과를 보기 전에 커밋한다. 근거: `QSF_1_2_VALIDATION_RESULTS.md`에서 현재 점수의 예측력을 찾지 못했다.

## 이미 본 것 (오염 공개)
- QSF 영역별 IC와 12-1 모멘텀 대조군을 전체 기간(2014~2026)으로 봤다.
- 가격 요인 스윙 점검(2022-02 ~ 2026-09)을 봤다.
- 그래서 시험 구간이 완전히 깨끗하지는 않다. 시험을 통과해도 전향 기록으로 더 확인해야 한다.

## 구간
- **개발:** 수익률 구간이 2021-12-31 이전에 끝나는 평가일만. 스윙은 20거래일, 장기는 252거래일 기준.
- **시험:** 2022-01-03 이후 평가일. 개발 단계 코드는 시험 구간 수익률을 계산하지 않는다.
- 평가일 21거래일 간격, 진입·청산·비용·유니버스·편입일 처리는 `QSF_1_2_VALIDATION_PROTOCOL.md`와 같다.
- 유니버스 조건: 주가 5달러 이상, 20일 평균 거래대금 2천만 달러 이상, 가격 이력 200일 이상.

## 후보 요인과 방향 (학술 문헌 기준, 사전 고정)
가격 요인은 전체 종목 안의 백분위, 재무 요인은 같은 GICS 섹터 안의 백분위로 바꾼다. 재무 값은 시점 기준 TTM이다.

| 요인 | 정의 | 좋은 방향 |
|---|---|---|
| mom_12_1 | 12개월 전~1개월 전 수익률 | 높을수록 |
| mom_6_1 | 6개월 전~1개월 전 수익률 | 높을수록 |
| rev_1m | 최근 1개월 수익률 | 낮을수록 |
| vol_252 | 1년 일간 변동성 | 낮을수록 |
| high_52w | 종가 / 52주 고가 | 높을수록 |
| earnings_yield | EPS / 주가 | 높을수록 |
| book_yield | 자본 / 시가총액 | 높을수록 |
| fcf_yield | FCF / 시가총액 | 높을수록 |
| roe | 순이익 / 자본 | 높을수록 |
| op_margin | 영업이익 / 매출 | 높을수록 |
| gp_assets | 매출총이익 / 총자산 | 높을수록 |
| accruals | (순이익 − 영업현금흐름) / 총자산 | 낮을수록 |
| asset_growth | 총자산 전년비 | 낮을수록 |
| share_change | 주식 수 전년비 | 낮을수록 |
| rev_growth | 매출 전년비 | 높을수록 |
| eps_growth | EPS 전년비 | 높을수록 |
| debt_equity | 부채 / 자본 | 낮을수록 |

요인은 이 17개뿐이다. 방향을 뒤집어 쓰지 않는다.

## 새 점수를 만드는 규칙 (자동 적용, 사람의 선택 없음)
스윙(20거래일)과 장기(252거래일)에 각각 적용한다. 개발 구간에서 수익률은 같은 날 평균을 뺀 초과 수익률이다.

1. 요인별 날짜별 IC를 계산한다. 방향을 반영해 좋은 방향이 양수다.
2. 평균 IC의 Newey-West t ≥ 2.0이고, 개발 구간 전반과 후반 모두 평균 IC > 0인 요인만 채택한다.
3. 점수 = 채택 요인 백분위의 단순 평균 × 100. 값이 있는 요인의 절반 미만이면 점수 없음. 가중치를 최적화하지 않는다.
4. 채택 요인이 없으면 그 전략의 새 점수는 만들지 않고, 시험도 하지 않는다.

## 시험과 판정
개발 결과를 커밋한 뒤 시험 구간에서 **한 번만** 실행한다. 코드가 두 번째 실행을 막는다.
주 검증은 전략별 하나다. 아래를 모두 충족하면 `WEAK_POSITIVE_EVIDENCE`, 아니면 `NO_EVIDENCE`다.

1. 평균 IC ≥ 0.02
2. Newey-West t ≥ 2.24
3. 시험 구간 전반과 후반 모두 평균 IC > 0
4. 시험 구간 전반과 후반 모두 5분위 스프레드(왕복 0.20% 차감) > 0
5. 상위 20% 평균 초과 수익률 > 0

참고 표시: 점수 구간별 결과, SPY 대비, 같은 구간의 QSF-1.1.2 IC. 시험 후 요인을 바꾸면 새 연구이며 전향 기록으로만 평가한다.

## 판정 이후
`WEAK_POSITIVE_EVIDENCE`여도 운영 점수를 자동으로 바꾸지 않는다. 사용자가 결정한다.
`NO_EVIDENCE`면 그대로 보고하고 같은 데이터로 다시 찾지 않는다.

## 한계
- 생존 편향은 그대로다. 현재 구성 종목만 평가한다.
- 시험 구간 약 4.8년, 장기 252거래일의 독립 표본은 약 4개여서 장기 판정은 근거가 약하다.
- 단순 보유 수익률만 보고, 손절·비중 규칙은 평가하지 않는다.
