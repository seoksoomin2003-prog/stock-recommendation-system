## 3. System Status vs. Recommendation Status Definition
We establish a clean separation of concerns:
- **Pipeline Execution Status**: `SUCCESS` (pipeline finished run), `PARTIAL` (run with fallback caches), and `LIVE DATA UNAVAILABLE` (pipeline halted).
- **Recommendation Validity**: `REAL RECOMMENDATION` (safe to execute) vs `DATA-INCOMPLETE / NO VALID RECOMMENDATION` (mock/quarantined data contamination or insufficient valid tickers).
- **Safe Mapping Contract**: The status mappings are defined in [reports/P6-13.5_STATUS_SEMANTICS_MATRIX.json](file:///Users/soominseok/Desktop/퀀트 예측 프로그램/reports/P6-13.5_STATUS_SEMANTICS_MATRIX.json).

## 4. Mock Data Policy & Firewall Semantics
We reject the overly broad "global blanket halt" in favor of a **Candidate-Level Quarantine** system:
1. **Candidate-Level Quarantine**: Any candidate with `MOCK` fundamental data or `UNAVAILABLE` price/volume data is quarantined *before* entering `MODEL_RANK_E` ranking. It receives zero weight/allocation.
2. **Min Ticker Check**: The pipeline requires at least **5 eligible REAL candidates** (the minimum required to fill the portfolio's TOP 5 slots under 30% individual constraints) to issue a `REAL RECOMMENDATION`.
3. The specific Candidate and Portfolio level rules for Cases A-G are defined in [reports/P6-13.5_MOCK_FIREWALL_MATRIX.json](file:///Users/soominseok/Desktop/퀀트 예측 프로그램/reports/P6-13.5_MOCK_FIREWALL_MATRIX.json).

## 5. Fundamental Score Contamination Path Trace
- **Trace Path**: `LocalFundamentalProvider (mode:local)` $\rightarrow$ `LLMFundamentalEngine.get_alpha_signal (data_status:MOCK)` $\rightarrow$ `batch_analyze_top_candidates / batch_analyze_full (data_status propagated)` $\rightarrow$ `main.py (aggregated_fundamental_statuses)` $\rightarrow$ `c["data_status"] / c["fundamental_status"]` $\rightarrow$ `DecisionEngine.evaluate_portfolio()`.
- **Firewall Guard**: In `evaluate_portfolio`, if `c["data_status"] == "MOCK"`, the candidate is immediately quarantined. This trace ensures that MOCK scores never reach `RankingEngine` or capital allocation.

---

## 6. Failure Semantics & Zero Value Guard
- **Volume Failure**: If `_download_yf` fails, `get_volume_data` returns a DataFrame filled with `np.nan` instead of `0`. This is represented as `volume_status = UNAVAILABLE`. Ticker is safely rejected during validation and liquidity filtering. Genuine zero volume remains distinguishable from API failure.
- **Momentum Failure**: If history is $< 14$ months, `calculate_momentum` returns a Series of `np.nan` with status `UNAVAILABLE`. Scoring Engine dynamically renormalizes weights among the remaining active factors.
