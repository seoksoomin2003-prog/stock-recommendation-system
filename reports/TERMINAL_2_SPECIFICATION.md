# 개인 투자 터미널 2단계 사양 (TERMINAL-2: 실제 포트폴리오·매매 보조, 미국)

- 상태: 구현 완료 (TERMINAL-2.0)
- 앞 단계: TERMINAL-1 (`reports/TERMINAL_1_SPECIFICATION.md`)
- 사용자 결정: P6-11B는 기준 모델로 고정한다. 터미널 → 포트폴리오·매매 보조 순서로 진행한다. 화면은 로컬 웹앱이고 미국 시장이 우선이다.

## 1. 목표

사용자가 직접 기록한 실제 거래로 보유 현황·손익·위험을 정확히 보여주고, 매매 결정을 돕는 계산을 제공한다.

- 주문 기능은 없다. 증권사와 연결하지 않는다.
- 숫자는 사용자가 정한 규칙(위험 한도 등)과 P6-11B가 기록한 계획으로 계산한다. 시스템이 수익을 보장하거나 매매를 권유하지 않는다.

## 2. 거래 기록 (저장)

- 파일: `data/terminal/journal.jsonl`.
  - 이 Mac에만 저장되고 git에서 제외된다(`.gitignore`의 `data/terminal/`).
  - 한 줄에 한 건씩 **추가만** 한다. 기존 줄은 수정하거나 삭제하지 않는다.
  - 각 줄은 앞 줄의 해시를 포함한다(해시 체인). 파일이 손상되면 화면에 "무결성 오류"로 표시한다.
- 기록 종류:

| 종류 | 필드 | 의미 |
|---|---|---|
| `DEPOSIT` / `WITHDRAW` | amount | 입금·출금 (외부 현금 흐름) |
| `BUY` / `SELL` | ticker, qty, price, fee | 매수·매도. 소수 주식 허용 |
| `DIVIDEND` | ticker, amount | 배당 수령 (세후 실수령액) |
| `FEE` | amount | 기타 비용 |
| `PLAN` | ticker, stop, target | 보유 종목의 손절가·목표가를 설정하거나 변경 |
| `VOID` | ref | 잘못 입력한 기록을 취소 (원래 기록은 남는다) |

- 기록할 때 전체를 날짜순으로 다시 계산해 검증한다. 다음은 거부한다:
  - 보유 수량보다 많은 매도(공매도는 지원하지 않는다);
  - 현금이 음수가 되는 기록 (먼저 입금을 기록해야 한다);
  - 미래 날짜, 0 이하 수량·가격.

## 3. 계산 규칙

- 원가: 이동평균법.
  - 매수 원가에 수수료를 포함한다.
  - 매도 실현손익 = (매도가 − 평균단가) × 수량 − 수수료.
- 평가: 최근 일봉 종가(Yahoo, 지연)를 쓴다. 장중에는 "장중·미확정"으로 표시한다. 시세가 없으면 평가액을 "—"로 표시하고, 합계에도 "일부 시세 없음"을 표시한다.
- 수익률:
  - 시간가중수익률(TWR): 일별로 계산하고 입출금 효과는 제외한다;
  - 비교 지수: 같은 기간 SPY.
- 계좌 가치 곡선: 거래 기록과 각 종목의 일봉 종가로 하루 단위로 다시 계산한다.
- 매매 성과: 매도 건별 실현손익, 승률, 평균 이익·평균 손실을 계산한다. 표본이 적으면(20건 미만) 해석하지 말라고 표시한다.

## 4. 위험 관리와 매매 보조

- 설정(`data/terminal/settings.json`), 사용자가 화면에서 바꾼다:

| 항목 | 기본값 |
|---|---|
| 1회 거래 위험(계좌 대비 손절 시 손실) | 1.0% |
| 종목당 최대 비중 | 20% |
| 섹터당 최대 비중 | 40% |
| 손절 근접 경고 거리 | 3% |

- 경고(화면 표시만):
  - 손절가 이탈;
  - 손절가 근접;
  - 목표가 도달;
  - 손절가 미설정;
  - 종목 비중 초과;
  - 섹터 비중 초과.
- 손절 시 총 위험: 보유 종목별 (현재가 − 손절가) × 수량을 합한다. 계좌 대비 %로 보여준다.
- 포지션 크기 계산기:
  - 입력: 진입가, 손절가. 손절가를 비우면 2 ATR(14일) 아래를 제안값으로 쓴다. P6-11B의 손절 규칙과 같다.
  - 수량 = 세 한도 중 가장 작은 값을 정수 주식으로 내림한다:
    - 위험 한도: 계좌 × 위험% ÷ (진입가 − 손절가);
    - 비중 한도: 계좌 × 최대 비중 ÷ 진입가;
    - 현금 한도: 현금 ÷ 진입가.
  - 어느 한도가 수량을 결정했는지 표시한다.
- P6-11B 대조 (읽기 전용):
  - 최근 전체 스캔의 TOP-5를 내 계좌 규모로 환산한다: 목표 수량, 1차 진입 수량, 모델 손절가.
  - 보유 여부를 표시한다.
  - 스캔이 오래되었으면(3일 초과) "오래됨"을 표시한다.

## 5. 화면

- 새 탭: **포트폴리오**(요약, 보유 종목, 경고, 계좌 가치 곡선 vs SPY, 매매 성과, 거래 기록 입력·목록), **매매 보조**(포지션 크기 계산기, 위험 설정, P6-11B 대조).
