# 주문 계획과 모의 체결 장부: 규칙 (PB-1, 2026-11-12)

사용자 결정(2026-11-12): 실행 계층은 **주문 계획 + 모의 체결 장부**까지 만든다. 증권사 연결과 실제 주문 실행은 없다. 비용은 토스증권 공시 수수료를 쓴다. 시작 금액, 매수 대상, 매도 규칙은 같은 날 사용자가 골랐다.

코드: `terminal/qsf/order_plan.py`, `terminal/qsf/paper_book.py`. 화면: 점수 탭 → 주문 계획·모의 장부.

## 1. 주문 계획 (실제 계좌와 모의 장부가 같은 규칙을 씀)

| 항목 | 규칙 |
|---|---|
| 후보 | 그날 기록된 점수 중 차단이 없고(`ACTIONABLE`) 진입 상태가 "지금 진입 가능"(`ENTRY_NOW`)인 종목 |
| 순서 | 점수 높은 순(스윙·장기를 함께 줄 세움). 동점이면 종목 코드 순 |
| 중복 방지 | 이미 보유한 종목, 같은 날 이미 계획된 종목(다른 스타일 포함)에는 주문을 만들지 않음 |
| 손절 | 스윙: 기록된 손절가(2 ATR). 장기: 기준 종가 − 5 ATR |
| 수량 | 아래 한도 중 가장 작은 값. 거래당 위험, 종목 비중, 현금, 스타일 비중(장기 70 : 스윙 30), 섹터 비중(40%), 거래대금 대비 주문 크기 |
| 한도 값 | 포트폴리오 설정값. 모의 장부는 기본값(2026-11-05 사용자 결정: 미국 장기 2%·25%, 스윙 1%·10%. 한국 장기 1%·20%, 스윙 0.5%·10%) |
| 주문 크기 한도 | 종목의 20일 평균 거래대금의 1%까지 |
| 최소 주문 | 계좌의 1% 미만이거나 한 주가 안 되는 주문은 만들지 않음 |
| 지정가 상한 | 기준 종가 + 0.5 ATR. 다음 시가가 이보다 높으면 따라가지 않음 |
| 현금 | 주문마다 지정가 상한 × 수량 + 매수 수수료를 미리 잡아 둠 |

### 비용

- **수수료·세금(공시값, 2026-11-12 토스증권 수수료 안내 확인):** 한국 편도 0.015%, 매도 시 거래세 0.20%. 미국 편도 0.1%, 매도 시 SEC 수수료 0.00206%.
- **환전 수수료**(정규 시간 0.05%, 그 외 0.5%)는 거래당 비용에 넣지 않는다. 달러 계좌를 따로 두기 때문이다.
- **슬리피지(추정, 실제 값 아님):** 편도 = 스프레드 가정(한국 15bp, 미국 10bp) + 주문 크기 충격. 충격 = 일간 변동폭(ATR ÷ 종가) × √(주문 금액 ÷ 20일 평균 거래대금). 제곱근 충격 모형의 계수 1을 그대로 쓴 가정이고, 실제 체결로 맞춘 값이 아니다.

## 2. 모의 체결 장부

| 항목 | 규칙 |
|---|---|
| 계좌 | 원화 1,000만 원, 달러 1만 달러. 서로 섞지 않음. 실제 포트폴리오 기록을 읽지도 쓰지도 않음 |
| 시작 | 2026-11-12 거래일의 점수로 첫 계획, 다음 거래일 시가부터 체결 |
| 매수 체결 | 계획 다음 거래일 시가 × (1 + 슬리피지 추정). 시가가 지정가 상한보다 높거나, 손절가 이하이거나, 시가가 없으면 체결하지 않고 그 계획은 버림 |
| 스윙 매도 | 종가 ≤ 손절가 → 다음 시가. 종가 ≥ 목표가 → 다음 시가. 보유 30거래일째 → 그날 종가 |
| 장기 매도 | 종가 ≤ 손절가(5 ATR) → 다음 시가. 그날의 장기 점수 < 40 → 다음 시가. 그날 점수가 없으면 점수로는 판단하지 않음 |
| 매도 체결 | 기준가 × (1 − 슬리피지 추정) − 수수료·세금 |
| 가격이 없는 종목 | 10거래일 연속 가격이 없으면 마지막 종가로 정리(거래정지·상장폐지) |
| 가격 파일이 다시 계산된 경우 | 장부에 적어 둔 종가와 가격 파일의 같은 날 종가가 0.5% 넘게 다르면(액면분할 등) 수량과 가격 기준을 그 비율로 옮김. 분할을 하락으로 읽지 않기 위함 |
| 하루의 순서 | 시가: 전날 정한 매도 → 전날 계획의 매수. 종가: 평가 → 매도 결정 → 다음 날 계획 |

- 손절·목표는 **종가 기준**으로 본다. 화면의 보유 판단("종가 손절선 이탈")과 같은 읽기이고, 미국 저장 가격에 고가·저가가 없기 때문이기도 하다. 장중에 손절가를 지나갔다 돌아온 경우는 손절로 보지 않고, 갭 하락은 다음 시가의 불리한 가격으로 체결된다.
- 부분 매도, 분할 매수, 재평가("보유·관찰")는 흉내 내지 않는다. 사람의 판단이 필요한 안내이기 때문이다.

## 3. 기록과 동시 실행

- 거래일마다 한 번 적고 고치지 않는다(`research_data/paper_book_kr`, `research_data/paper_book_us`, 해시 연결). 하루의 기록은 전날 기록이 남긴 계좌 상태에서 이어 간다. 과거를 다시 계산하지 않는다.
- 기록은 한 번에 하나만 쓴다(파일 잠금). 자동 실행이 겹치면 뒤의 실행은 기다렸다가 이미 적힌 날을 건너뛴다.
- 그날의 계산은 그날까지의 가격만 읽는다(시험: 뒤의 가격을 지워도 결과가 같음).

## 4. 읽는 법과 한계

- **판정 전 참고**다. 한 계좌의 경로는 점수가 맞는지의 근거가 아니다. 점수의 판정은 `reports/QSF_LIVE_FORWARD_PROTOCOL.md`의 기록으로만 한다. 이 장부에는 통과·미달 판정이 없다.
- 실제 체결과 다르다: 시가에 원하는 수량이 모두 체결된다고 보고, 슬리피지는 추정이며, 장중 가격을 보지 않는다.
- 한국 스윙 점수는 과거 근거가 없고(2026-11-11 재구성), 미국 스윙 점수는 과거 검증에서 근거를 찾지 못했다. 장부의 수익·손실을 점수의 성적으로 읽지 않는다.
- 규칙을 바꾸면 버전(PB-2…)을 올리고 바꾼 날을 적는다. 이미 적힌 기록은 고치지 않는다.
- 주문을 보내지 않으며 투자 자문이 아니다.
