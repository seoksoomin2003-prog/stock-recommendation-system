# QSF 1.1 화면 명세

터미널의 '점수' 탭(`terminal/static/qsf.js`)과 `python app.py qsf evaluate`.

- 색: BUY 초록 `#16A34A`, SELL 빨강 `#DC2626`, HOLD·관찰 회색 `#64748B`, REDUCE 주황 `#D97706`. 미보유 40~54.99점 AVOID는 주황, 40점 미만은 빨강.
- 색만으로 전달하지 않는다. 판정은 ink 색 글자 + 색 테두리·점으로 그려 두 테마 모두 대비를 확보한다.
- 카드: 종목, 시장, 전략, 가격, 점수, 판정, 구간, 신뢰도, 반영률, 모델 버전, 데이터 날짜.
- 점수와 신뢰도를 항상 따로 표시한다. 게이트에 걸린 종목은 점수를 남기고 '차단'으로 표시한다.
- 세부: 영역별 막대와 점수, 진입 상태, 보유 계획, 무효화 조건, 판단이 바뀌는 조건, 직전 기록 대비 변화, 요인별 계산표.
- 순위표: 시장·전략별 상위 50. 전향 검증표: 코호트별 기록 수와 판단.
- 모든 문구는 실제 요인·규칙에서 만든다.
- 확인: 1100px과 375px 폭에서 가로 넘침 없음(2026-11-05 브라우저 확인).
