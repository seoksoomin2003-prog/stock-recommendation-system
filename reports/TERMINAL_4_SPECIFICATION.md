# 개인 투자 터미널 4단계 사양 (TERMINAL-4: 자동 실행과 알림)

- 상태: 구현 완료 (TERMINAL-4.0). 예약 설치는 사용자가 직접 실행함.
- 사용자 결정 (2026-11-05): 알림은 텔레그램과 맥 알림.

## 매일 작업 (`python app.py automation run`)
- 순서: 도전자 기록(LAB) → P6-11B 스캔(SCAN, `QPP_CAPITAL`이 있을 때만) → P6-20 추적(TRACK) → 백업(BACKUP) → 경고·요약 전송.
- 작업마다 별도 프로세스로 실행하고, 완료된 미국 거래일당 한 번만 성공 처리한다. 실패한 작업만 다음 예약에 다시 시도한다.
- 예약: 한국 시간 07:10, 08:10, 12:10, 20:10과 로그인 시. 할 일이 없으면 아무것도 보내지 않는다.
- 빠진 거래일은 소급 기록하지 않고 요약에 표시한다.

## 알림
- 경고는 일봉 종가 기준이다. 장중 이탈은 알리지 않는다.
- 새 경고와 계속되는 경고를 구분한다. 실제 전달된 뒤에만 '새 경고'에서 내린다.
- 텔레그램 토큰은 `.env`에만 둔다. 오류는 예외 종류나 HTTP 상태만 남긴다(토큰이 URL에 들어가기 때문).
- 메시지에는 종목, 가격, 비중이 들어가고 계좌 총액은 넣지 않는다.

## 백업
- `~/QuantEngineBackups/<거래일>/`에 거래 기록과 장부를 복사하고 해시로 검증한다. 날짜 이름 폴더만 최근 60개를 남긴다.

## 설치
- `python app.py automation install` / `uninstall`. plist에는 비밀값을 넣지 않고 로그인 셸 환경을 쓴다.
