# 한국 스윙 점수 구성 변경과 한국 장기 점수 문구 (2026-11-11, QSF-1.2.0)

사용자 결정(2026-11-11): "한국 스윙 점수에서 차트 항목 빼고 지금 들어가도 되는지를 보는 진입 조건으로 쓰자", "10번도 진행 … '한 구간에서는 설명했고 다른 구간에서는 확인되지 않았다' 수준으로 낮추자". 결정 목록의 9번과 10번이다.

## 바뀐 것
1. **한국 스윙 점수(프로필 `KR_SWING_V2`):** 기술 영역 다섯 요인(추세 구조, 상대 강도, 모멘텀, 돌파·거래량, 변동성 구조, 배점 40)을 점수에서 뺐다. 점수는 재무 10, 시장 국면 20, 위험·실행 20, 이벤트 10으로 계산한다(값이 있는 요인의 배점 합계로 나누는 방식은 그대로).
2. **기술 영역 요인은 지우지 않았다.** 계속 계산해 화면에 "참고 · 점수 미반영"으로 보이고 원장에도 저장된다. 그래서 이전 수식 점수를 원장만으로 다시 계산할 수 있다.
3. **진입 판단은 그대로다.** 이미 있던 규칙(`holding.entry_status`)이 차트 위치를 본다: 점수 55 이상, 실적 발표 임박 아님, 20일 고점 돌파 시 거래량 확인, 비용 반영 손익비 1.5 이상(아니면 눌림 대기). 새 규칙이나 새 기준값은 만들지 않았다. **이 진입 판단은 검증된 적이 없다.**
4. **화면 문구와 과거 성적 표(10번):** 한국 장기 점수 설명을 "한 구간(2019~2026)에서는 순위를 설명했고 다른 구간(2016~2019)에서는 확인되지 않았으며, 두 구간 모두 상위 종목이 시장을 이기지 못했다"로 낮췄다. 과거 성적 표에 2016~2019 줄을 더했다. 표의 한국 스윙 줄은 "이전 구성"으로 표시했다.
5. 미국 점수, 한국 장기 점수, 점수 구간(70점 매수 후보 등), 차단 조건, 요인 수식은 바뀌지 않았다.

## 적용 전 확인 (기록 없이 2026-11-10 거래일을 새 코드로 채점해 원장과 맞댐)
원장의 2026-11-10 기록은 QSF-1.1.8이다. 아래 차이에는 같은 날 아침 적용한 재무 입력 수정(QSF-1.1.9)의 영향도 섞여 있다.

| 한국 스윙 (296종목) | 이전 | 새 구성 |
|---|---:|---:|
| 점수 중앙값 / 최고 | 34.9 / 63.8 | 35.2 / 56.8 |
| 70점 이상 (매수 후보) | 0 | 0 |
| 55점 이상 (관찰) | 8 | 4 |
| 평균 자료 충족률 | 0.853 | 0.757 |
| 신뢰도 표시: 보통 / 낮음 / 판단 불가 | 294 / 1 / 1 | 46 / 247 / 3 |
| 실행 가능 / 차단 / 자료 부족 | 281 / 14 / 1 | 279 / 14 / 3 |

- 이전 점수와 새 점수의 순위 상관은 0.50이다. 296종목 중 267종목이 1점 이상, 158종목이 5점 이상, 69종목이 10점 이상 움직였다. 점수가 사라진 종목은 없다.
- 새 점수는 같은 날 원장 요인값으로 계산한 "기술 영역을 뺀 점수"(도전자 점수)와 253종목에서 0.01점 안으로 같다. 나머지 43종목의 차이(최대 7.8점)는 재무 입력 수정의 영향이다. 같은 입력에서 두 수식이 정확히 맞는 것은 시험으로 확인했다(`tests/test_qsf_kr_swing_v2.py`).
- **신뢰도 표시가 대부분 "낮음"으로 내려갔다.** 자료가 늘 채워져 있던 기술 영역(40점)이 빠지면서, 한국에서 값이 없는 요인(변동성 지수 5점, 신용·유동성 3점, 내부자 거래 3점은 전 종목, 실적 발표일 4점은 대부분)의 비중이 100점 중 15점에서 60점 중 15점으로 커졌기 때문이다. 기준(충족률 0.70, 0.80, 0.90)은 바꾸지 않았다. 충족률이 0.70에 못 미쳐 "판단 불가"가 된 종목이 1개에서 3개로 늘었다.
- **한국 스윙 매수 후보(70점 이상)는 전에도 없었고 지금도 없다.** 점수 수준이 낮은 것은 구성 변경과 무관한 기존 상태다. 구간 기준은 손대지 않았다.
- 한국 장기 점수의 차이(54종목이 1점 이상)는 아침의 재무 입력 수정에서 온 것으로, 그때 확인한 수와 같다.

## 정직하게 적어 둘 것
- **기술 영역을 뺀 종합 점수는 과거 구간에서 한 번도 시험하지 않았다.** 근거는 "기술 영역이 세 구간에서 순위를 거꾸로 매겼다"와 "위험 영역만 쓰면 순위 상관이 +0.14~0.15였다"는 참고 수치다. 같은 과거 구간으로 새 점수를 시험하면 좋게 나올 수밖에 없어 하지 않았고, 앞으로도 하지 않는다.
- 근거가 된 현상(한국의 단기 되돌림)은 이미 알려진 것이고, 앞으로 약해질 수 있다.
- 새 점수에서 시장 국면 영역의 비중은 20%에서 33%로 커졌다. 이 영역은 같은 날 모든 종목에 같은 값이라 순위에는 영향이 없고 점수 수준만 옮긴다.
- 대상(거래대금 상위 300)이 과거에 시장보다 부진했다는 문제는 그대로다.

## 앞으로의 확인
- `reports/QSF_KR_SWING_PRIOR_PROTOCOL.md`: 이전 수식 점수를 매일 라이브 점수 옆에 적는다. 20거래일 표본 12개가 끝나면 한 번 평가한다(약 1년). 이전 수식이 뚜렷이 나았다면(`PRIOR_BETTER`) 되돌릴지 묻는다.
- 기존 도전자 기록은 이제 라이브 점수 자체의 근거를 답한다. 라이브 전향 판정(`QSF_LIVE_FORWARD_PROTOCOL.md`)도 그대로 진행한다.
- 첫 QSF-1.2.0 기록은 2026-11-11 거래일(2026-11-12 아침 실행)이다.
