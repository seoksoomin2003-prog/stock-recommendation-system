# 한 사람이 쓰기에 무엇이 모자란가 (2026-11-23, 커밋 `02aed81`)

상용 제품의 기능을 기준으로 삼지 않았다. 한 사람이 자기 돈으로 쓸 때 필요한 것만 본다.

## 1. 꼭 필요한데 없는 것

| 모자란 것 | 왜 필요한가 | 누가 할 일인가 |
|---|---|---|
| **실제 계좌의 기록** | 거래 기록이 0건이다. 주문 수량, 손절, 한도, 보유 점검, 나쁜 날의 축소, 성향의 크기 효과가 실제 보유에 대해 돈 적이 없다. '오늘' 탭은 "계좌 미기록 … 후보 322건"이라고만 말한다 | 사용자. 어제 만든 "이미 가지고 있는 종목 추가"로 입금 기록 없이 넣을 수 있다 |
| **점수가 통한다는 근거** | 없으면 순위는 정렬일 뿐이다 | 시간. 2027년 12월의 첫 판정까지 기록이 빠지지 않아야 한다 |
| **기록이 제때 쌓이는 환경** | 맥이 잠들면 그날 기록이 늦거나 빠진다(한국 9일 중 3일이 늦었던 적이 있다) | 사용자. 전원과 잠자기 설정 |
| **다른 디스크의 백업** | 백업이 기록과 같은 디스크에 있다 | 사용자. `.env`의 `QPP_BACKUP_DIR` |
| **틀린 첫 문장의 수정** | 보유·관찰 카드 416장의 첫 줄이 거꾸로다 | 코드 |
| **빠진 자료가 점수를 올리지 않게** | 밸류에이션이 없으면 "강력 매수 후보·지금 진입 가능"이 된다 | 코드(규칙 선택은 사용자) |

## 2. 있으면 판단이 나아지는 것

- **"지금 진입 가능"의 뜻을 표시 자체에.** 쉬운 설명만 "막는 이유가 없다는 뜻"이라고 말한다. 표시, 카드 문장, 비서의 설명, '오늘' 탭의 "322건"은 시점처럼 읽힌다.
- **성향 설정의 정확한 설명.** 화면은 "70점 / 67점"이라 하지만 주문 계획은 55점부터 담는다. 공격적 성향이 나쁜 날의 제동을 0.75배로 만든다는 것과 본인 한도를 1.5배로 키운다는 것이 접힌 표 안에 있다.
- **쉬운 설명에 위험 표시 넣기.** 합병 공시, 시장 상태, 실적일. 지금은 합병으로 가격이 묶인 종목에 "기준에 잘 맞는 편"이라고만 한다.
- **오래된 재무의 표시.** 1년 넘은 보관본으로 계산하면 신뢰도를 낮추거나 판단하지 않기.
- **종목 화면의 순서.** 점수 카드가 위원회·위험·당일 점검·예측 뒤에 온다. 누르기 전에 숫자가 220개가 넘는다.
- **한국 거래정지 종목의 표시.**
- **매일 메시지에 "시장 상태를 읽지 못함"을 적기.**

## 3. 있어도 되고 없어도 되는 것

- 실제 휴대폰에서의 다듬기(글자 크기, 차트의 터치, 버튼 안 설명 읽기). 연결 자체는 만들어져 있고 실제 기기로 본 적이 없다.
- 쉬운 설명 버튼을 분석 노트, 위원회의 종목 판정, '오늘' 탭에도.
- 코인 계좌의 한도와 국내 거래소 가격.
- 환율로 생긴 손익의 계산.
- 판정 일정표를 접어 한 줄로.

## 4. 한 사람에게 필요 없는 것 (만들지 말 것)

- 여러 사용자, 로그인, 권한, 결제, 가입 흐름.
- 클라우드 배포, 큰 규모의 분산 처리, 가용성 보장.
- 외부에 공개하는 API.
- 자동 주문.
- 요인을 더 늘리는 것. 실질적으로 독립인 축은 3~5개이고 검증된 것이 없다. 요인을 더하면 설명할 것만 늘어난다.
- 투자자 엔진이나 포트폴리오 종류를 더 늘리는 것. 지금 여섯 개도 성과가 확인된 것이 없다.
- 성향의 단계를 더 잘게 나누는 것. 지금 세 단계의 숫자에도 근거가 없다.

## 5. 지인에게 나눠 주는 것에 대하여

사용자가 지인 몇 명에게 나눠 줄 생각을 밝혔다. 이 평가의 범위는 한 사람의 사용이지만, 평가 결과에서 바로 따라오는 것만 적는다.

- 점수가 검증되지 않았다는 것을 이 프로그램은 여러 곳에서 말한다. 그러나 카드 자체와 주문 계획에는 그 말이 없다. 주식을 공부해 본 적 없는 사람은 "매수 후보"를 추천으로 읽는다.
- 쉬운 설명이 그런 사람을 위한 기능인데, 지금은 위험 표시 일부를 빠뜨리고 적자 회사에 "비싸지 않다"고 말하는 경우가 있다.
- 나눠 주기 전에 1절의 코드 항목 둘과 2절의 쉬운 설명 항목은 고쳐야 한다.
