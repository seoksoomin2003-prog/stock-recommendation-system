# P6-17.4.1 VSCode Runtime Guide

1. Open the repository folder itself in VSCode.
2. Run **Python: Select Interpreter** from the Command Palette.
3. Select the workspace interpreter shown as `.venv/bin/python`. If it is absent, choose **Enter interpreter path** and select `.venv/bin/python` inside the opened workspace.
4. Run **Python: Refresh All Environment Managers** if VSCode opened before `.venv` was created.
5. Use **Run Python File** or the `Python: Main Pipeline (Live)` debug configuration. Both use the workspace-local interpreter.
6. Use **Testing: Refresh Tests**, then **Testing: Run All Tests**. The workspace configuration uses unittest discovery under `tests/`.

Verify the integrated terminal with:

```bash
.venv/bin/python -c "import sys; print(sys.executable)"
```

It must print a path ending in `.venv/bin/python`, not a machine-specific system path. The live configuration is not a P6-17.5 validation command; do not run a full universe until that phase is explicitly started.
