## 한 쪽 결론

**판정: LEVEL 2 — FUNCTIONAL BUT UNPOLISHED (기능은 갖췄으나 다듬어지지 않음) · 51.5 / 100**

- 이 터미널은 기능 폭이 넓고, **문장으로는 매우 정직합니다**. "점수가 높다고 수익이 더 좋았다는 근거는 아직 확인되지 않았습니다"(17), "신뢰도(자료의 양)"(22), 가격 범위 FC-1의 "오를지 내릴지는 말하지 않습니다"(24), 결측과 0의 구분(app.js:467)은 상용 도구보다 낫습니다.
- 그러나 **눈이 먼저 닿는 시각 언어는 반대로 말합니다**. 34 px 소수점 점수, 70점에서 회색이 초록으로 바뀌는 알약, 초록 "과거 점검 통과" 배지, 정의 없는 "신뢰 97", "정상 추천"은 검증된 도구처럼 보이고, 정직한 문장은 작은 회색 글씨·접힌 상자·hover 툴팁·페이지 맨 아래에 있습니다(레드팀 #1~#4).
- **틀린 숫자가 그대로 그려집니다**. 한국 종목 장중 시가 0 봉이 가격 칸을 뚫고 거래량 칸까지 내려가고(D1, 31), 위원회가 이미 버리는 배당수익률 10.05 %를 종목 화면은 사실로 보여 주며(D2), 오늘 탭 첫 숫자(S&P 500 하루 −3.70 %)가 "1개월" 꼬리표에 붙어 한 달 수치로 읽힙니다(V3, 01).
- **사용자가 실제로 쓰는 어두운 테마**에서 선택된 시장·보기·전략 버튼과 주 버튼의 글자 대비가 2.70:1입니다(흰 글자 on #6d9bff, style.css:42,102,135).
- **휴대폰에서 순위를 쓰기 어렵습니다**. 머리글 약 415 px, 열어 둔 카드가 순위 위에 남아 순위 표가 y≈8,790 px에서 시작하고(D4), 760 px 아래에서는 판단·진입 열이 숨겨집니다(style.css:438, W1).
- 프레임워크 이전이나 전면 재설계는 필요 없습니다. **표시 층의 단계적 재설계**(잘못된 숫자 가드 → 어휘·색의 정직성 → 점수 탭·종목 상세 위계 → 토큰·부품 → 폰 배치)로 LEVEL 3에 갈 수 있습니다. 점수·공식·기준·매매 규칙은 하나도 바꿀 필요가 없습니다.

## 영역별 평가

### 1. 시각 디자인 — 11 / 20
- **근거**: 색 token 30개와 테마 전환(style.css:1-26), 측정표의 글자 크기 12종 이상·radius 8종, 스타일 없는 입력 2개(#qsfticker, #cha-q; 17·10·39), 대비 재계산(흰 글자 on #6d9bff 2.70).
- **강점**: 패널·카드·배지·세그먼트의 기본 부품이 한 체계. 시장 개요(03)·차트분석(10)·순위 표(18)는 연구 도구로 보기에 손색없음. 출처·받아온 시각이 거의 모든 패널에 붙음.
- **약점**: 위계 단계가 촘촘해 오히려 위계가 안 보임(패널 제목 15 px vs 본문 14 px, UI-06). 확신을 주는 요소(큰 점수, 초록 알약, 초록 "통과")가 불확실성 문장보다 시각적으로 무거움(레드팀 #2·#3). 내부 식별자 노출(UI-07). 잘못된 숫자(D1·D2·D3).
- **심각도**: P1 (대비·확신 시각 언어), P2 (토큰·입력·식별자)
- **확신도**: 높음
- **권고**: `--on-accent` 토큰으로 대비 해결, 글자 7단계·radius 3단계 token, 판단 색과 가격 색 분리, 식별자는 '기술 정보' 접힘으로.

### 2. 정보 구조 — 9 / 20
- **근거**: 7 묶음 + 17 하위 탭 + 점수 탭 4 보기(EVIDENCE), 점수 탭 머리 블록 약 270 px 반복(D6), 시장 상태 전체 블록 3곳 반복(D8), 점수 상세 6,750 px·13,194자·meta 260줄, 이름 겹침(W8).
- **강점**: 오늘 탭이 헤드라인 문장으로 결론부터 말함. 카드 안 순서(요약 → 올린/깎은 요인 → 영역 → 진입 → 계획)가 질문 순서와 맞음(22). 추적·검증 보기의 접힘 구성(21).
- **약점**: 점수 상세가 요약→근거→세부의 층 없이 한 스크롤(UI-01). 같은 문단 반복(UI-02, W6, W7). 마지막 연 카드가 순위보다 앞에 옴(D4). '내 계좌' 3번, '점수' 2번, '모의' 장부 4개(W8). 급락일 헤드라인과 "근거 없음" 문장 위치(레드팀 #1).

- **확신도**: 높음
- **권고**: 점수 탭 상단을 한 줄 상태 띠로, 상세 카드 맨 위 요약 띠 + 섹션 접힘, 헤드라인에 시장 상태 반영(등급 분류는 그대로), 하위 탭 이름 정리.

## FINAL VERDICT — 열 가지 질문

**(1) 지금 UI가 전문 투자 리서치 플랫폼처럼 보이는가?**
부분적으로만 그렇습니다. 시장 개요(03), 차트분석(10·11), 순위 표(18), FC-1 범위 막대(24)는 상용 리서치 도구 옆에 놓아도 어색하지 않습니다. 그러나 점수 상세는 6,750 px의 긴 글이고, 스타일이 빠진 입력창(17·10), 내부 식별자(22·26), 시가 0 봉(31)과 10 % 배당 같은 눈에 띄는 잘못된 숫자가 "잘 만든 개인 도구"의 인상을 남깁니다.

**(2) 정보 구조가 분명한가?**
아니오. 7 묶음·17 하위 탭이라는 큰 틀은 이해할 만하지만, 묶음 → 하위 탭 → 보기의 3단에 시장·스타일·성향 전환이 겹치고, 이름이 겹치며(W8), 같은 머리 블록과 시장 상태 문단이 반복되고(D6, D8), 종목 상세에는 요약 → 근거 → 세부의 층이 없습니다. "어디부터 볼지"를 화면이 정해 주지 못합니다.

**(3) 투자 인사이트를 이해하기 쉬운가?**
"왜 이 점수인가"는 쉽습니다. 점수를 올린·깎은 요인 상자와 "50 + 19.8 = 69.8" 검산이 좋은 설명 장치입니다(22). 반면 "들어가도 되나·얼마나·손절은" 같은 실행 질문의 답은 점수 탭, 주문 계획 보기, 매매 보조의 세 곳에 흩어져 있습니다(W3).

**(4) 점수와 추천이 시각적으로 믿을 만한가?**
문제는 반대 방향입니다. 검증되지 않은 점수가 **실제보다 더 믿음직하게** 보입니다. 34 px 소수점 점수, 70점 경계에서 바뀌는 초록 알약(13위 70.2 초록, 15위 69.8 회색; 18), 초록 "과거 점검 통과", 정의 없는 "신뢰 97", "정상 추천"이 그렇습니다. 동시에 D1·D2·D3 같은 틀린 숫자가 신뢰를 깎습니다. 과신과 불신을 함께 부르는 상태입니다.

**(5) 불확실성이 분명하게 전달되는가?**
문장으로는 그렇고, 시각적 위계로는 아닙니다. FC-1과 "자료의 양" 정의는 모범적입니다. 하지만 "근거 없음" 문장은 오늘 탭 맨 끝 meta 글씨(assistant.js:103)이고, "신뢰도"의 뜻과 합병 공시의 위험 설명은 hover 툴팁에만 있어 폰에서는 보이지 않습니다(qsf.js:233-234, 351). 불확실성을 같은 크기, 같은 줄로 끌어올려야 합니다.

**(6) 데이터 시각화가 충분히 강한가?**
개념 설계는 강하고 무결성은 약합니다. 불확실성 표현(FC-1), 결측 표시, 출처 표시는 우수합니다. 하지만 그리기 층이 자료를 검사하지 않고(D1), 축 숫자 형식이 두 차트에서 다르며(V8), 초록 한 색이 다섯 가지 뜻을 가지고, "위험" 방향이 화면마다 반대입니다(V4). P0·P1을 고치면 16점 안팎이 현실적입니다.

**(7) 매일 리서치에 쓸 만한가?**
Mac에서는 그렇습니다. 아침 확인은 0클릭, 점수 이유는 2~3클릭입니다. 휴대폰에서는 아직 아닙니다. 머리글 약 415 px, 순위 표가 y≈8,790 px, 판단·진입 열이 숨겨집니다(38~40, W1, D4).

**(8) 재설계가 필요한가?**
프레임워크 이전이나 전면 재작성은 필요 없습니다. 빌드 없는 vanilla 구조는 이 사용자에게 맞습니다(폰에서도 같은 파일이 돔). 필요한 것은 **표시 층의 단계적 재설계**입니다. 토큰과 작은 부품 층(`ui.js`), 점수 탭과 종목 상세의 위계, 폰 배치, 그리고 불확실성을 앞으로 끌어내는 시각 언어입니다. 약 24개 테스트 파일이 정적 파일 문자열을 고정하므로 테스트 수정이 비용의 큰 몫입니다(F20).

**(9) 무엇을 먼저 고칠까?**
P0 세 건입니다. ① 시가 0 봉을 그리지 않기(D1), ② 배당수익률 이상값을 종목 화면에서도 "원자료 이상"으로 표시(D2), ③ 지수 타일에 "1일"·"1개월" 꼬리표(V3). 그 다음 첫 묶음은 텍스트·CSS 수준의 P1입니다. 어두운 테마 `--on-accent`, 인증처럼 들리는 어휘 정리("신뢰" → "자료 충족" 등), "위험" 방향 꼬리표, 급락일 헤드라인, 장기 진입 문구 통일입니다.

**(10) 어떤 디자인 방향을 택할까?**
**하이브리드: Koyfin식 모던 리서치 골격 + 표 화면에만 터미널 밀도 + "불확실성 우선" 표시 규칙.** 요약 띠와 카드로 위계를 세우고(폰에 맞음), 순위·스크리너·시장 개요는 넓은 화면에서 촘촘하게 씁니다. 모든 점수 옆에 검증 상태와 자료 충족을 같은 크기로 붙입니다. 세부 값은 DESIGN_DIRECTION_PROPOSAL.md에 있습니다.

## 등급

**LEVEL 2 — FUNCTIONAL BUT UNPOLISHED**

- LEVEL 1이 아닌 이유: 17개 하위 탭이 실제 자료로 동작하고, 다섯 뷰포트 어디서도 페이지가 깨지지 않으며, 색 token·테마·이스케이프·오류 문장처럼 제품 수준의 기반이 있습니다.
- LEVEL 3이 아닌 이유: 틀린 숫자가 그대로 그려지고(D1·D2), 첫 화면 첫 숫자의 뜻이 바뀌어 읽히며(V3), 사용자가 쓰는 테마에서 선택 상태 대비가 AA에 미달하고(A1), 휴대폰 순위가 사실상 쓰기 어렵고(W1·D4), 디자인 시스템이 색에서 멈춰 있습니다(F1·F3). P0 전부와 P1의 대부분을 닫으면 LEVEL 3(Professional Beta)으로 볼 수 있습니다.

- 전문가 에이전트 6명(제품 디자인, 금융 데이터 시각화, UX 작업 흐름, 프론트엔드·디자인 시스템, 접근성·반응형, 독립 비판)이 각자 보고서를 쓰고, 총괄 평가자가 종합했습니다.
