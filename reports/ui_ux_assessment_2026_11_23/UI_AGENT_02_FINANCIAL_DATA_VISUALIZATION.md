# UI 에이전트 2 — 금융 데이터 시각화 평가 (2026-11-23)

범위: 차트, 스파크라인, 히트맵, 점수 카드, 순위 표, 요인 막대(영역 막대, 올린 점수/깎은 점수 상자), 가격 범위 막대(FC-1), 위원회 숫자판, 검증 표, 숫자 형식, 색의 뜻, 결측·지연 표시, 오해 위험.
읽기 전용 점검입니다. 점수·공식·기준·매매 규칙은 바꾸자고 하지 않으며, 보이는 방식만 다룹니다.

## 요약

- 이 터미널의 시각화는 **"숫자에 붙은 설명의 정직함"이 강점이고, "그림 자체의 무결성"이 약점**입니다. 점수 카드·예측 범위·차트분석 신호에는 "맞을 확률이 아님", "검증 안 됨", "점수 미반영", "0이 아님" 같은 꼬리표가 거의 빠짐없이 붙어 있습니다. 개인용 도구로는 보기 드문 수준입니다.
- 반면 캔버스 그림과 핵심 숫자 몇 곳은 자료를 검사하지 않고 그대로 그립니다. 장중 시가 0인 봉(D1), 다른 화면에서는 이미 버리는 배당수익률 10.05%(D2), 87줄 전부가 "—"인 비율 열(D3)이 그 예입니다. 설명문은 신중한데 그림은 자료를 의심하지 않는 비대칭이 있습니다.
- 가장 큰 오해 위험은 네 가지입니다.
  1. 오늘·시장 개요 타일에서 하루 등락률이 "1개월" 꼬리표에 붙어 보입니다.
  2. "위험" 점수의 방향이 화면마다 반대입니다. QSF 영역 점수는 높을수록 안전하고, 위원회 "하방 위험"과 위험 등급은 높을수록 위험합니다.
  3. 위원회·투자자 카드의 "신뢰" 숫자에는 QSF 카드의 "(자료의 양)" 단서가 없습니다.
  4. 한국 시장에서도 초록=상승, 빨강=하락을 씁니다. 사용자가 쓰는 증권사(토스증권) 화면은 빨강이 상승이라 같은 빨강이 반대 뜻이 됩니다.
- 제안 점수: **20점 만점에 13점**.

## 강점

1. **신뢰도와 정확도를 분리했습니다.** 카드의 "신뢰도(자료의 양)"에 "맞을 확률이 아닙니다"라는 title이 있고(qsf.js:351), 순위 표의 "자료 보통" 배지도 같습니다(qsf.js:445). 점수와 신뢰도를 늘 따로 보여 준다는 원칙이 파일 첫 줄에 있습니다(qsf.js:1).
2. **FC-1 가격 범위는 불확실성 표시의 모범입니다**(24, forecast.js:82-134).
   - 50%와 80% 범위를 겹친 띠로 보여 주고, 손절·목표를 같은 축 위에 세로선으로 겹칩니다.
   - "움직임의 크기이며 오를지 내릴지는 말하지 않습니다"라는 문장을 붙였습니다.
   - 과거 포함률, 변동성 묶음에 따른 치우침, 급변일에 실패한 비율까지 적습니다.
   - 방향 쪽 숫자는 기본적으로 접혀 있고 제목이 "초과 수익 0, 확률 50%"입니다.
3. **결측을 0과 구분합니다.** `DASH`/`없음`/`스캔 밖`/`자료 없는 요인 n` 배지가 있고, 재무표에는 "—는 0이 아닙니다"라는 주석이 붙습니다(app.js:467). 점수 막대에도 결측 상태가 따로 있습니다(qsf.js:36).
4. **출처·받아온 시각·장중 미확정 표시가 거의 모든 그림에 붙습니다.** `meta()`, `liveBadge` "장중·미확정"을 썼습니다(app.js:39, 45; 06, 10, 31).
5. **점수 분해를 산술로 보여 줍니다.** 올린/깎은 요인 상자에 "50 + 19.8 = 69.8점"이 적혀 있어(22, qsf.js:330) 점수가 어디서 왔는지 숫자로 따라갈 수 있습니다.
6. **차트분석의 고전 신호를 정직하게 표시합니다.** 신호 표식마다 범례에 "(모두 검증 안 됨)"이 붙고(chart.js:185), 지금 상태 위에 "IC 음수였다"는 경고가 있습니다(11).
7. **히트맵 범례가 색의 범위를 숫자로 밝힙니다.** "−3% ~ 0 회색 ~ +3%, 그 너머는 같은 색"(04, map.js:107)처럼 범위를 적었고, 점수 모드는 빨강/초록이 아닌 파랑 한 가지의 진하기로 칠해 등락색과 섞이지 않습니다(map.js:35-38).
8. **표의 숫자 열에 `tabular-nums`를 씁니다**(style.css:31). 대부분의 가격은 `toLocaleString("ko-KR")`로 천 단위 구분을 합니다.
9. **비교 차트에 통화 경고가 있습니다.** "수익률은 각 종목의 통화 기준이며 환율을 반영하지 않습니다"(12).
