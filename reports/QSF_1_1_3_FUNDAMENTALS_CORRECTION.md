# QSF-1.1.3: 미국 재무값 읽기 수정과 점수 영향

작성일 2026-11-06. 점수 계산식, 가중치, 구간은 바꾸지 않았습니다. 고친 것은 SEC 10-K에서 재무값을 읽는 방식입니다.

## 고친 결함

| 결함 | 예 (수정 전 → 후) | 수정 |
|---|---|---|
| 멈춘 항목을 최신 값처럼 읽음 | AMZN FCF 마진 18.5% → 1.1%, QCOM ROE 277.6% → 44.8% | 회사의 최신 결산보다 400일 넘게 먼저 끝난 항목은 없는 값으로 처리 |
| 계약 매출 등 일부 매출을 전체 매출로 읽음 | ESS 영업이익률 9,587% → 47.6%, URI 107.5% → 24.7% | `Revenues` 같은 전체 매출 항목을 먼저 읽음 |
| 회사가 쓰는 항목 이름을 읽지 못함 | TFC 순이익 없음 → 읽음, XEL 매출 멈춘 값 → 최신 값 146.7억 달러 | 회계 의미가 같은 이름만 추가 |

항목 이름은 회계 의미로 골랐고, 점수 결과를 보고 고르지 않았습니다. 세전이익으로 영업이익을 대신하는 것처럼 뜻이 다른 값은 쓰지 않습니다. 없는 값은 0으로 처리하지 않습니다.

## 남은 한계

- **부채 과대 계산:** 장기부채 항목이 멈추면 기존 규칙대로 총부채를 부채로 씁니다. 실제 차입금보다 크게 잡혀 FE, WM 같은 종목에는 다소 불리합니다.
- **일부 매출:** CPT, HBAN, MTB는 전체 매출 항목이 없어 일부 매출만 읽힙니다. 이 종목들의 매출 기반 비율은 믿을 수 없습니다.
- **은행 매출 없음:** FITB, RF, SYF, TFC 등은 총매출 항목을 공시하지 않아 매출이 없는 값으로 남습니다. 임의로 합산하지 않았습니다.
- **과거 검증:** 지난 검증과 연구 보고서는 수정 전 읽기로 계산됐습니다. 판정이 달라지는지는 시험하지 않았습니다. 이번 수정으로 과거 결론이 뒤집혔다는 뜻도, 그대로라는 뜻도 아닙니다.
- **예측력:** 이 수정은 입력 오류를 고친 것이며, 점수의 예측력을 증명하지 않습니다.
- **기록:** 이미 원장에 있는 과거 점수는 바꾸지 않습니다. 새 기록은 `QSF-1.1.3`으로 구분됩니다.
