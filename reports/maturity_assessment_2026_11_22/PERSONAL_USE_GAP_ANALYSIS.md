# 개인 사용 관점의 격차 분석 (2026-11-22)

한 사람이 자기 돈으로 쓰는 도구에 무엇이 모자란지만 적는다. 경쟁 제품에 있다는 이유로 넣은 항목은 없다.

## 1. 개인 사용에 꼭 필요한데 모자란 것

| 모자란 것 | 왜 꼭 필요한가 | 근거 |
|---|---|---|
| 판단에 닿는 표시가 서로, 그리고 자기 자신과 맞는 것 | 매일 보는 첫 문장과 "지금 진입 가능"이 틀리면 나머지가 아무리 정확해도 판단을 그르친다 | 카드 첫 문장(미국 20건), 장기 진입 가능 62%, 스윙 손익비 모순, 장기 진입 조건의 구멍 |
| 빠진 자료가 점수를 올리지 않는 것 | 나쁜 수치가 빠질수록 좋아 보이면 가장 조심해야 할 종목이 가장 위로 온다 | 밸류에이션이 빠지면 75.1 → 90.1 |
| 실제 계좌의 기록 | 위험 한도, 업종 한도, 청산 경고, 나쁜 날 50% 한도가 모두 계좌를 읽는다. 지금은 계좌·보유·알림 규칙이 0이라 한 번도 실제로 돈 적이 없다 | 주문 계획 `NO_ACCOUNT`, 위험 화면 `NO_HOLDINGS` |
| 다른 디스크의 백업 | 기록은 다시 만들 수 없다(원자료를 보관하지 않는다). 디스크 하나가 고장 나면 2030년까지의 판정 기반이 사라진다 | 백업이 같은 디스크 |
| 가장 중요한 경고가 첫 화면에 있는 것 | "기록이 며칠 뒤처졌다", "백업이 오래됐다", "텔레그램이 실패했다"는 경고가 연구실 탭에만 있다 | 오늘 탭에 없음 |
| 순위 1위에 붙어야 할 표시 | 합병으로 가격이 묶인 종목이 스윙 1위인데 순위 화면과 텔레그램에는 표시가 없다 | TECH, 2026-11-20 |

## 2. 중요한 개선

| 개선 | 기대 효과 |
|---|---|
| 신뢰도의 뜻을 화면에 적기("자료가 있다는 뜻이고 맞을 확률이 아님") | 504개 중 498개가 "높음"인 표시를 올바로 읽게 된다 |
| 종목 화면의 순서 바꾸기(점수 카드를 위로, 위원회와 예측은 접기) | 지금은 누르기 전 약 7,000자, 숫자 315개. 점수 카드가 화면의 54~60% 아래에서 시작한다 |
| 주의 문장을 한곳에 모으기 | 한 화면에 서로 다른 주의 문장이 20~28개라 가장 중요한 것이 묻힌다 |
| "매수 후보" 표시에 "점수 구간의 이름"이라는 꼬리표 | 초록색 표시가 추천처럼 읽힌다 |
| 판정이 2027년 12월 전에는 나오지 않고 "구분되지 않음"일 가능성이 높다는 안내를 접지 않고 보여 주기 | 기대치를 맞춘다 |
| 재무 입력의 이상값 점검(부채가 총부채에 견줘 터무니없이 작은 경우) | PHM 같은 사례가 위험 요인을 만점으로 만든다 |
| 이력의 빈 구간 검사 | 40거래일이 빠져도 지금은 모른다 |
| 순위 규칙 장부의 자동 적용을 회전율 규칙처럼 알림으로 | 하락장에서 실력 없이도 6~27% 채택 |
| 휴대폰에서 보기(같은 와이파이 안에서, 읽기 전용) | 사용자가 밝힌 계획. 지금은 서버가 이 컴퓨터 안에서만 응답한다 |

## 3. 있으면 좋은 것(선택)

- 증권사 추정치의 변화를 읽는 것(기록은 11월 22일부터 쌓이는 중이다. 유일하게 "새 정보"를 더하는 후보이지만 지금은 시험할 수 없다).
- 금리·수익률 곡선을 시장 상태 옆에 참고로 표시.
- 미국 가격의 두 번째 출처로 하루 한 번 대조(사용자가 지금은 야후만 쓰기로 정함).
- 오류 문구의 한국어화(30개 중 5개만 돼 있다).
- 로그 남기기(지금은 예외 이름만 남는다).
- 원자료의 하루 스냅샷 보관(과거의 하루를 다시 만들 수 있게 된다. 디스크를 쓴다).

## 4. 이미 충분하거나 과한 것

개인 도구로서 **더 늘리지 않는 것이 나은** 부분이다.

- 전향 판정 30건과 비교 장부들: 주된 판정은 넷이다. 나머지는 유지 비용이 들고, 많을수록 우연히 통과하는 것이 생긴다.
- 다섯 투자자 엔진, 위원회, 여섯 포트폴리오: 설명에는 도움이 되지만 검증이 없고 화면을 무겁게 한다. 늘리지 말고 접어 두는 쪽이 낫다.
- 테스트 약 2,000건: 충분하다. 글자를 고정하는 테스트(약 4%)는 줄여도 된다.

## 5. 필요 없는 상용 기능

다음은 평가에서 감점하지 않았고 만들 이유도 없다: 여러 사용자 계정, 결제·구독, 가입 안내, 고객 지원, 클라우드 확장, 인증·규제 준수 증명, 외부에 여는 API, 가용성 보장, 판매·마케팅 기능. 자동 매매도 이 프로그램의 범위가 아니다.

## 6. 한 줄 요약

모자란 것은 기능이 아니라 **일치와 실사용**이다. 표시들이 서로 맞고, 빠진 자료가 점수를 올리지 않고, 실제 계좌로 한도가 돌고, 백업이 다른 곳에 있으면, 이 프로그램은 지금의 근거 수준에서 낼 수 있는 쓸모를 거의 다 낸다. 그 위는 2027년 말의 판정이 정한다.
