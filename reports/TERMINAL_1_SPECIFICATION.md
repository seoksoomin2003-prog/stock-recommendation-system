# 개인 투자 터미널 1단계 사양 (TERMINAL-1, 미국 우선)

작성일: 2026-11-04 · 상태: **구현 중** · 결정사항(사용자, 2026-11-04):
1. P6-11B는 기준 모델로 그대로 둡니다. 도전자 모델은 옆에서 함께 관찰하며, 3단계에서 추가합니다.
2. 1단계는 터미널 화면입니다.
3. 형태는 로컬 웹앱입니다.
4. 미국 시장을 먼저 합니다.

## 1. 목표

무료 공개 데이터로 동작하는 1인용 투자 터미널입니다. 브라우저에서 `http://127.0.0.1:8765`로 열고, 내 맥에서만 동작합니다.

- 외부 접속은 받지 않습니다. 서버는 `127.0.0.1`에만 바인딩합니다.
- 주문 기능은 없습니다.
- 동결된 P6-11B 모델과 P6-20 트래킹은 **읽기만** 합니다.

## 2. 화면 (한국어)

| 탭 | 내용 | 데이터 |
|---|---|---|
| 시장 개요 | 주요 지수(S&P 500, 나스닥, 다우, 러셀 2000), VIX, 미 10년물 금리, 달러인덱스, 원/달러, 유가, 금, 섹터 ETF 11종의 종가, 전일 대비, 1개월 변화 | Yahoo (일봉 종가, 지연) |
| 종목 | 캔들 차트(3개월/1년/5년) + 이동평균 20/50/200 + 거래량, 핵심 지표, 연간 재무(최근 5개 회계연도), 최근 SEC 공시 목록(원문 링크) | Yahoo, SEC companyfacts, SEC submissions |
| 거시 | 미 10년·2년 금리, 장단기 금리차, 연방기금금리, CPI 전년비, 실업률, 비농업고용, 원/달러 | FRED (키 없는 CSV) |
| 관심종목 | 추가·삭제, 종가·등락 표시, 클릭 시 종목 화면 이동 | Yahoo; 목록은 `data/terminal/watchlist.json`에 로컬 저장 |
| 모델 | 기준 모델 P6-11B의 최신 전체 스캔(TOP-5, 워치리스트), 페이퍼 트래킹 상태, 도전자 모델 자리(아직 없음) | `runs/`, `tracking/` (읽기 전용) |

## 3. 데이터 원칙 (기존 원칙 유지)

- 모든 패널에 **데이터 상태**(REAL / STALE / UNAVAILABLE), 기준일, 출처를 표시합니다.
- 값이 없으면 "-"로 표시합니다. 0이나 추정치로 채우지 않습니다.
- 캐시: `data/terminal/cache/`에 저장합니다. 유효 시간은 시세 15분, 재무 20시간, 공시 1시간, 거시 6시간입니다. 갱신에 실패하면 이전 값을 **STALE** 표시와 함께 보여줍니다.
- 시세는 실시간이 아닙니다. 일봉 종가(지연) 기준이며, 화면에 그렇게 표시합니다.
- SEC는 `SEC_USER_AGENT`가 설정된 경우에만 조회합니다. 값은 화면, 로그, 응답 어디에도 노출하지 않으며, 요청 간격은 초당 10회 미만으로 유지합니다.
- FRED 데이터는 개인·비상업적 이용이 허용되고 출처를 표시해야 합니다(이용약관 확인, 2026-11-04). 저작권 표시가 있는 시리즈는 사용하지 않습니다.
- 재무 표는 **표시용**입니다. SEC 연간 프레임(`CY####`, 기말 `CY####Q4I`)을 사용하며, P6-11B 입력 규칙(P6-20-A)과는 별개입니다. 모델 입력으로 쓰지 않습니다.

## 4. 구조

| 파일 | 역할 |
|---|---|
| `terminal/sources.py` | 외부 데이터 조회 (Yahoo, SEC, FRED). 테스트에서는 가짜로 교체할 수 있습니다. |
| `terminal/cache.py` | TTL 파일 캐시와 STALE 대체 |
| `terminal/services.py` | 화면별 데이터 조립 (개요, 차트, 기업, 공시, 거시, 관심종목, 모델) |
| `terminal/server.py` | 표준 라이브러리 HTTP 서버, JSON API, 정적 파일 제공 |
| `terminal/static/` | 한국어 화면 (HTML/CSS/JS, 외부 라이브러리 없음, 캔버스 차트) |
| `app.py terminal [--port 8765] [--open]` | 실행 명령 |

추가 패키지, 유료 서비스, Docker는 없습니다. M2 8GB에서 동작합니다.

## 5. 이후 단계 (미착수)

- **2단계:** 실제 보유 종목 입력, 손익, 매일 규칙 점검, 주문 계획서, 매매 일지.
- **3단계:** 워크포워드 백테스터(비용 반영)와 도전자 모델. P6-11B와 나란히 실전 관찰하며, 동결 모델은 변경하지 않습니다.
- **4단계:** 정기 실행과 알림.
- 한국 시장 화면은 미국 다음에 추가합니다.
