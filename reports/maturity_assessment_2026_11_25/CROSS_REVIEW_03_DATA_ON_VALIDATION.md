## 요약

AGENT 06이 근거로 삼은 기록된 결과들은 **미래 참조 면에서는 대체로 깨끗합니다.** 재무는 접수일 기준이고(미국 `fundamentals.py:264`, 한국 `markets/kr/dart.py:16,170`은 "평가일보다 엄격히 앞선 접수일"), 한국 시험의 대상은 평가일마다 그날 KRX 자료로 다시 골랐으며 상장폐지 종목도 들어 있습니다. 남은 편향은 대부분 **시험에 불리한 쪽**(정정 공시 지연, 폐지 종목을 마지막 거래가로 청산)이거나 **방향이 정해지지 않는 쪽**(미국 생존 편향이 IC에 주는 효과)입니다. 그래서 AGENT 06의 결론(미국 근거 없음, 한국 장기는 순위만, 돈 조건 실패, 지금 공식은 미시험)은 **그대로 성립합니다.** 고칠 점은 하나입니다. W7의 "과거 수치가 낙관적"은 절대 수익과 구간 표에는 맞지만 IC에는 맞다고 할 수 없습니다. 문서 모순 지적(W11)은 맞습니다.

## 따로 본 세 가지

**1. 정정 공시(10.5%).** 정정본이 원래 접수일로 들어오면 미래 참조지만, 실제로는 정정본의 접수번호(그래서 늦은 날짜)로 들어옵니다(제 캐시 점검: 예 2024년 결산이 2025-08-13 접수). 결과는 "그 해 결산이 정정일까지 없는 것으로 보임"이며, 정보 손실이고 미래 참조는 아닙니다. 시험 결과를 좋게 만들 수 있는 경로는 찾지 못했습니다. 다만 OpenDART가 정정본에 정정본의 접수번호를 준다는 것은 캐시 패턴으로 추정한 것이고 API 문서로 확인하지 않았습니다(PARTIALLY VERIFIED).

**2. 한국 Yahoo 가격 결함.** 과거 시험은 모두 KRX 자료만 썼습니다. Yahoo 한국 봉의 결함(102/300, QSF-1.1.8에서 고침)은 1.1.8 이전 라이브 기록(11-04~11-06 한국, "Yahoo Finance 일봉")에만 닿고, 실전 판정은 2026-11-23부터 읽으므로(`live_forward.py`의 `FIRST`) 어떤 판정에도 들어가지 않습니다. 지금도 매일 한국 기록의 마지막 봉은 Yahoo이지만, 11-23 종가는 KRX와 300/300 일치했습니다(`evidence/agent_05/kr_tail_vs_krx.json`).

**3. 미래 참조 점검의 범위.** AGENT 06의 서술이 맞습니다. 엔진 항목은 한국 가격 몇 종목만 넣고 재무·이벤트·국면·실적일을 비웁니다(`lookahead.py:118-122`). 과거 시험의 재무 시점은 이 점검이 아니라 코드의 필터(`fundamentals.py:264`, `dart.py:170`)가 지킵니다. 필터는 짧고 읽기 쉬워 저는 맞다고 판단했지만, 자동 점검으로 보증되지는 않습니다. 미국 경로는 점검 밖입니다.

## AGENT 06 주장 하나: 계획서 141행과 코드 47행의 모순

**맞습니다(VERIFIED).** `QSF_LIVE_FORWARD_PROTOCOL.md:141`은 "차단이 늘면 그 종목은 판정의 표본에서 빠진다"고 적고, 129행도 판정이 "실행 가능 여부를 읽는다"고 적습니다. 코드(`live_forward.py:47`)는 점수가 있고 `INSUFFICIENT_DATA`가 아니며 `data_date`가 세션과 같은 행을 모두 셉니다. `BLOCKED`는 빠지지 않습니다. 파일 안에서 `BLOCKED`나 `gates`를 따로 거르는 곳은 없습니다. 115행(1.5.0 공개)은 "차단된 종목은 이전처럼 표본에 남는다"고 해서 코드와 맞습니다. 즉 문서끼리 어긋나고 코드는 처음 등록한 규칙대로입니다. 데이터 쪽에서 덧붙일 점: 거래정지 차단(1.5.2)으로 막힌 종목(11-23 한국 3종목)은 표본에 남으므로, 정지 기간의 평평한 봉이 판정 표본의 결과 계산에 들어갑니다. 수는 작아 영향은 미미합니다.
