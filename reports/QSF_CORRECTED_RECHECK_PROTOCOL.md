# 고친 재무값으로 과거 검증 재계산: 사전 계획

작성일: 2026-11-06. 재계산 결과를 보기 전에 커밋한다.

## 왜 하는가

`QSF_1_1_3_FUNDAMENTALS_CORRECTION.md`에서 재무값 읽기 오류를 고쳤다. 과거 검증은 수정 전 읽기로 계산됐으므로, 입력 오류 때문에 판정이 달라지는지 확인한다. 점수를 좋아 보이게 조정하는 작업이 아니다.

## 이미 본 것 (오염 공개)

- 아래 네 검증의 수정 전 결과를 모두 봤다. 판정은 모두 `NO_EVIDENCE`이거나 채택 요인 없음이었다. 스윙은 `vcp`, `rev_sector_1m`이 개발을 통과했으나 시험에서 `NO_EVIDENCE`였다.
- 2026-11의 라이브 점수 변화(현재 시점 단면)는 봤다. 과거 구간의 수익률과 수정 후 점수의 관계는 보지 않았다.
- 같은 날짜와 같은 표본을 다시 쓰므로, **어떤 결과가 나와도 독립된 새 증거가 아니다.**

## 바꾸는 것

재무 입력만 바꾼다. 가격, 종목 구성, 섹터, 평가일, 비용, 점수식, 가중치, 판정 조건은 그대로다.

1. 전체 매출 우선, 같은 뜻의 항목 이름 추가: 현재 `fundamentals.US_FLOW`, `US_INSTANT`.
2. 멈춘 항목 제거: 각 평가일에 그날까지 공시된 값만 보고 `fundamentals.drop_stale_series`를 적용한다. 미래 공시로 판단하지 않는다.
3. 회사 번호가 바뀐 종목의 이전 공시 연결: `reports/qsf/QSF_INSIDER_CIK_ALIASES.json`의 40개 종목과 `sources.CIK_PREDECESSORS`.

재무값은 SEC에서 다시 내려받아 `data/qsf/research/facts_corrected/`에 따로 저장한다. 기존 `facts*` 폴더와 기존 보고서 JSON은 덮어쓰지 않는다.

## 재계산 범위

| 번호 | 대상 | 판정 조건 | 결과 파일 |
|---|---|---|---|
| R1 | 오픈소스 표본 확대 검증 (`QSF_OPEN_VALIDATION_PROTOCOL.md`), 가장 넓은 표본 | 주 판정: 변형 C, 스윙 20일과 장기 252일. 기존 5조건 그대로 | `QSF_CORRECTED_OPEN.json` |
| R2 | 독립 시험의 가설 (`QSF_OOS_TEST_PROTOCOL.md`): 변형 A, 장기 252일, 2011-03~2012-12 | 기존 5조건 그대로 | `QSF_CORRECTED_OOS.json` |
| R3 | 문헌 17요인 연구의 개발 단계 (`QSF_RESEARCH_SCORE_PROTOCOL.md`), 2021년까지 | 기존 채택 규칙 그대로 | `QSF_CORRECTED_RESEARCH.json` |
| R4 | 스윙 24요인 연구의 개발 단계 (`QSF_SWING_RESEARCH_PROTOCOL.md`), 2021년까지. 재무를 쓰는 `sue`만 달라진다 | 기존 채택 규칙 그대로 | `QSF_CORRECTED_SWING.json` |

재계산하지 않는 것:

- **최초 검증과 Yahoo 재검증:** R1 표본의 부분집합이다.
- **내부자 연구:** 재무 입력을 쓰지 않는다.
- **2022년 이후 시험(R3, R4):** 개발 단계만 다시 계산한다. 시험 구간 수익률은 계산하지 않는다.

기존 일회성 보호 장치는 그대로 둔다. 기존 시험 보고서를 지우거나 덮어쓰지 않는다. 각 재계산도 결과 파일이 있으면 다시 실행을 거부한다.

## 결과를 어떻게 읽는가

- R1, R2가 여전히 `NO_EVIDENCE`이고 R3에 채택 요인이 없으면, 재무값 오류가 과거 결론의 원인이 아니었다고 기록한다.
- 판정이 `WEAK_POSITIVE_EVIDENCE`로 바뀌거나 R3, R4에 새 채택 요인이 나오면, 재계산을 멈추고 수치와 함께 사용자에게 보고한다. 같은 표본이므로 가설로만 다루고, 전향 기록이나 사용자가 승인한 새 시험으로 확인한다.
- **어떤 결과가 나와도 라이브 점수, 가중치, 구간, 안내 문구를 자동으로 바꾸지 않는다.**
- 결과를 본 뒤 기준, 항목 이름, 멈춤 판단 일수를 바꾸지 않는다. 계산 오류를 발견해 고치면 그 사실과 수정 전 수치를 결과 보고서에 공개한다.
